# 独立网页验收记录（2026-10-09）

## 结论

**待验收开发版。** 可复现源码和可解压本地运行的静态候选已生成；自动化单元/组件、静态边界、打包完整性及本地 HTTP 路由检查通过。真实浏览器、视觉、真机、真实数据库、生产公共 API、Nginx 预发布与旧服务无回归验收均**未执行**，不得据此上线。

正式菜品仅从专用同源公开 GET API 读取。服务端默认关闭、明确 ID allowlist 为空；网页不会用历史整理菜谱或测试菜兜底。因此尚不能承诺真实公开菜数、自动生成覆盖或来源许可已放行。历史来源阅读的 18/305/372 数不是当前运行时库存，也不是人类食品安全专家审核。

## 实现覆盖与取舍

| 范围 | 已实现与自动化覆盖 | 必须补充的实际验收 |

个人数据留在浏览器减少向服务器传输，也意味着无账号同步、换浏览器或 origin 不会自动搬家。线上菜源避免另造静态版本，但目录不可用时自动候选可能受限。未知份量、身份与质量保持未知，会减少自动合并/生成能力。没有服务端事务目录 revision，跨页相同总数下的内容变化仍可能无法发现。

## 测试先行与自审发现

- 首批发布/路由失败门禁：19 个测试因缺打包器/本地服务器而失败；补实现后通过。线上边界另有缺检查器的失败测试后转绿。
- 自审复现并修复：源指纹被换成伪摘要仍能打包；改为重新计算与 receipt 比较。Nginx 根入口未显式 no-cache；根与 index.html 都补重新验证头。两项失败回归均转绿。
- 追加自审发现构建后SVG主动脚本及release父目录符号链接未被拒绝；两项失败回归后修复。产物CSS/SVG现在保留主动标记检查，打包在写入前拒绝符号链接输出父目录。
- 运行时 MIT 文本原仅在候选根目录，静态路由不会公开。新增失败回归后，将全文同时放到固定版本的 SHA256 命名资源并由 HTML license 链接引用，转绿。
- 拒绝未经自动静态检查的 candidate、缺许可/缺资源、审阅后改字节、额外文件、危险 ID、符号链接、私有/外部/历史绑定、伪依赖 receipt 和包内篡改；相同候选的 ZIP 字节一致。
- 本地 HTTP 验证严格区分：API 503 是本地明确 stub；/health 的 candidate-local-only 不声称真实服务器健康。旧 /main 和 ACME 在 helper 中 404，不能代替生产保留路由比较。

- 独立审查指出首次receipt前的JS/CSS传递资源缺失可能被遗漏。已用锁定工具链Rolldown 1.2.13解析JS AST、css-tree 3.2.1解析CSS URL，检查全部发出资源；缺资源、逃逸、外部、跨release、无法静态确定的模块引用拒绝。真实Vite输出删除SVG，以及缺chunk/CSS、JS/CSS转义解析均有回归覆盖。
- 独立审查指出示例API的^~前缀绕过旧点路径拒绝。改回普通/api/前缀；测试静态比较普通公共路径与/api/.env、嵌套点路径的选择策略，不把静态模型当Nginx或线上非回归证据。
- 第一次复查修正的聚焦红灯有14项失败，补修后41项聚焦检查通过；该轮首个绿灯尝试还发现诊断文字不匹配与测试模型漏解析单行deny，均修正并重跑。

- 追加独立复查发现image-set字符串图像源不产生CSS Url节点，曾绕过资源闭包。当前产品不用此语法，现明确拒绝image-set/-webkit-image-set，包括大小写及转义函数名；8项缺文件、远程、转义及资源实际存在的失败回归转绿。url资源检查保留；import策略由下面的最终修复收紧。

- 完整分支审查发现“保留当前编辑”后没有可用保存动作，导致草稿不能直接接续保存到日历。本轮补充“保存当前编辑”：从当前保留的草稿/设置构造新请求，不复活旧失败载荷；同时修改时原子保存，明确采用最新内容仍放弃本页编辑。新请求使用新 UUID，失败重试保留同一载荷和 UUID；确认旧事务的精确重放只在未观察到更晚修订时解除冲突。再次外部写入仍须重新审阅。组件回归覆盖直接保存、组合设置、偏好单独保存、反复冲突、未知完成结果与日历闭环；仍不等于原生多标签浏览器验收。
- 完整分支审查发现CSS转义的import at-rule字符串目标可绕过闭包。本轮对at-rule名称先解码再忽略大小写，明确拒绝全部import语法（包括文件存在的本地import），无审核receipt写入；10项缺文件、外部字符串/转义、大小写、URL及本地存在策略回归覆盖。没有扩展通用CSS解析器或访问外部URL。
- 本轮初始聚焦红灯：5项保留编辑保存动作缺失、10项import策略断言失败；补实现后又确认精确重放虽成功仍留下自身冲突，追加针对性修复后全部转绿。完整web最终为473项；包括两项后续外部写入/新请求身份保护检查。

这些是自动静态与自审证据。完整分支独立审查指出的两项缺陷已作本轮针对性修复，仍待独立聚焦复查；任何上线许可都未包含在这些测试结果中。
