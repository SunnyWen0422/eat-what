# 做菜阅读与继续（T16）

单菜与本餐继续使用独立入口。正文读取结构化步骤，食材可随时展开，长步骤不截断。前后步骤可以换行排列，切步骤后滚到页首，避免还停在上一长步骤的底部。菜品切换使用水平滚动区，并显示选中状态。

本机进度按账号/API、日期、餐次、计划版本隔离；条目按菜品ID分开，保留正在看的菜及步骤。无版本菜谱保存可读内容签名（菜品ID、版本、步骤和食材文本）进行精确比较，内容变化后提示并只重置相应菜的步骤。没有内容签名的旧阅读位置不推断仍然有效，首次改用新格式时安全重置。签名只用于本地相等判断，并非安全摘要或服务端事实。

储存不可用时仍可看步骤，并说明阅读位置未保存。翻到最后一步、切菜及重开不会记录吃过；未来本餐和单菜入口都不直接记录实吃，已有实际记录、原请求恢复及版本确认仍走原记录弹层。

50项Node检查通过，包括无版本内容变化、同名不同ID、结构化内容、空步骤、切账号、重开、储存失败以及原整餐/实吃回归。原生横向切菜、大字、滚动和键盘仍待T23。
