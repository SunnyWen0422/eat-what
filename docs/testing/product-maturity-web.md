# 网页体验统一（T19）

网页继续以浏览器独立数据为边界，不调用微信私有写接口，也不假设与小程序账号同步。沿用A基础/F菜品主体：保留菜图及回退、圆角、语义标签、对话框焦点闭环、返回与skip link。

今天的保留操作与小程序同名，推荐理由仅取本机收藏/实际记录事实，不凭空补理由。内部槽位ID改为用户可读的菜品次序。日历优先展示实际记录；有实际记录时原安排可展开；一餐主要动作明确，采购/编辑/删除收在更多。购物清单保留形态、部位、原量及来源，把重新生成和删除收起，编辑仍走原事务。过大采购内容显示可操作的中文错误，原数据和选中来源不动。

字号从固定像素改为相对单位。阅读菜谱详情时初始焦点落在弹窗面板，避免自动滚到中部的第一个可操作元素；表单仍聚焦首个输入。选中按钮的前景/背景同时切换，保留按压位移动效，避免过渡中出现白字浅底。减少动态效果继续生效。

验证：

- 467项网页非打包检查通过。完整523项曾出现522通过、1项Windows临时目录重命名EPERM；单独复测打包文件时又在另一重命名用例遇到同类错误。完整失败日志保留，56项发布打包检查整体不算通过，留T25定位，不改断言或删除测试。
- 类型、构建、独立网页边界检查通过。
- 隔离Chromium 2项通过：保存/取消编辑/采购连续链路；320/390/430/1280 × 1/1.3/2字号下详情和日历。测量水平溢出、按钮触控尺寸、字号与详情初始滚动，保留24张截图。修复前焦点与选中颜色的问题均有失败证据。

浏览器只连接本次独占本机服务，公共目录使用合成响应，全部其他HTTP/WebSocket被阻断。这不是线上、微信原生、真机或真实模型验收。网页月选日是可换行日期选择器；窄屏不强行压缩七列触控目标，不据此宣称原生日历几何已验证。
