# 本地前端读取线上菜库：2026-10-13

用户授权提交推送本轮 A/F 样式，并允许本地使用线上真实数据验证。执行范围为公开菜库 GET 与匿名鉴权检查，没有数据库直连、业务写入、模型请求、配置覆盖或线上部署。

## 当前连接方式

- 小程序正式源码 `utils/config.js` 保持 `https://chishenme.icu/api`，后端、登录和 V4 开启。微信开发者工具应打开正式仓库目录，而非名称带“原生验收 · 合成数据”的隔离导出项目。私人页面需要真实微信登录，且用户操作保存/收藏等会影响线上账号记录。
- 网页使用 `web` 下的 `npm run dev:online`，本机开发代理只允许公开菜库 GET，保留 HTTPS 证书校验并剥离令牌、Cookie；个人计划等仍存于当前浏览器。
- 前端通过后端读取线上数据库，不把数据库账号或密码放到前端，也没有把隔离 MySQL 启动器指向生产数据库。

## 已知差异

当前线上公开菜库抽样返回字段中没有 `image`，网页实测详情没有图片元素，因此按设计回退到分类图标。本次不能用图片请求错误或证书错误解释这个结果，也不能据此断言数据库图片缺失。前端已支持当前菜库提供的合规图片；网页展示真实菜图还需单独补齐后端公开媒体字段并部署验证。小程序原有菜谱接口与公开网页菜库是不同接口。

本次只验证公开菜库读取和页面展示，不代表新助手、私人数据读写、真实模型、数据库事务及真机键盘已验收。线上前端暂停发布状态继续保留。
