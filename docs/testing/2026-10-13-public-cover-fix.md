# 网页公开菜库封面字段修复

## 原因与修复

公开菜库的 SQL 已查询 `IMAGE AS image`，但 `PublicDishDTO` 和 `PublicCatalogService.project` 未将封面加入返回契约。网页前端已支持封面，也无法显示服务端未返回的地址。

此次为公开列表与详情统一增加可空 `image`。仅在既有白名单、系统菜和已发布校验通过后返回封面；用户身份、私人质量证据、步骤图片等仍不公开。没有改变数据库结构、公开菜品范围或历史内容版本计算。

封面接受不含账户密码的 HTTP/HTTPS 域名地址，统一 HTTPS；空值、无效格式、本机地址、IP 字面量和过长值返回 null，不阻断菜谱浏览。后端只提供地址，不下载外部图片。网页沿用图片失败时显示分类图标的行为，媒体不进入本地菜单快照和备份。

## 生效边界

这是本地后端代码修复，线上接口需要部署匹配版本后才会返回图片字段。没有通过网页开发代理绕过鉴权或扩大公开数据范围。
