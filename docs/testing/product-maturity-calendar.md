# 日历与实际用餐（T14）

日历日期的读屏名包含完整年月日、选中状态、计划及实际记录摘要；月首空位不再响应点击。日期输入仍验证真实公历日，跨月及北京时间零点由原日期工具处理。

餐次详情按当前状态保留一个主要动作：已有实际记录则更正、到期计划则记录这餐、未来计划则准备食材、空餐则安排。调整、复制、采购、助手和状态管理统一收在更多中。历史菜单采购明确写“按这份菜单准备食材”，保留原日期和餐次来源。日历总入口先选择餐次，避免助手默认餐次与所选日期混用。

实际记录确认继续显示日期、餐次和菜名；选择或关闭不会写入。外食支持多行输入。“没按这份计划做”改为明确的“这餐没吃”，避免将外食误记为未进餐。未知保存仍用原请求恢复，计划版本、实际版本及删除墓碑规则不变。统计仅调整相同含义的标签，计算方式不变。

49项Node检查通过：新日期/主动作/模板检查、原实际保存与未知恢复、计划移除后的实际阅读、复制跨餐和账号隔离。原生读屏、键盘、多行高度与2倍字体仍待T23，数据库事务仍待T21，不能由这些检查推定已经验收。
