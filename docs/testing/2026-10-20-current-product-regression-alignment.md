## 原因与修正

此前 [界面审查报告](2026-10-20-ui-review-and-selected-sheet.md) 记录的六项失败，
其中五项是过时的文案、结构或资源数量断言；一项是测试环境不允许创建目录链接，
随后无条件清理又以 ENOENT 遮住了原始 EPERM。

| 检查 | 本轮修正与保留的验证 |
| --- | --- |
| 原生输出目录边界 | 仅在链接创建成功后删除链接，创建失败时保留原始错误；在允许创建临时链接的本地执行环境实际验证大小写路径及 junction 祖先保护，没有跳过用例或放宽生产守卫。 |
| 购物费用 | 检查费用功能可见且已展开时才展示明细的四种组合；无报价与部分缺价分别说明，参考合计、实际支出及有效报价绑定保持独立。 |
| 饮食回顾 | 不恢复重复介绍；检查实际饮食概览的条件、明确吃过的餐次、空记录入口，以及计划执行独立对照的说明。已有饮食统计行为回归一并执行。 |
| 首页恢复提示 | 不依赖已经移除的内联设置面板；检查恢复及忌口警告在主内容中，不受设置弹窗可见条件控制，并保留冲突、条件修改、搭配不足和失败后的操作验证。 |
| 图标资源 | 取消固定 37 个的断言，验证清单与实际基础图标一致、名称不重复、必要操作图标与导航图标齐备；保留 SVG/PNG 文件有效性检查。 |
| 购物食材行 | 不恢复“用量待核对”等无效文本；检查缺失分量留空、来源可访问名称、来源事件，以及忙碌/删除模式的保护。分量安全标记、原始输入和来源身份仍保留。 |
