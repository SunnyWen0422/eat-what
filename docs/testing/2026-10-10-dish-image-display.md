# 菜品图片展示验收（仅本地）

## 展示规则

- V4 本餐菜单、菜谱浏览、已选菜品、常用菜单等复用 `compact-dish-row`：有图片地址优先展示图片，64 × 64px、14px 圆角、居中裁切，不拉伸。
- 菜品详情：图片容器 18px 圆角，保留点击查看原图；没有图片或加载失败时显示对应菜品分类的简笔画。
- 简笔画只做占位，不替换菜谱保存的图片字段。图片地址变化后重置失败状态；忽略上一张图片迟到的失败事件。
- 空白地址按无图处理，沿用 HTTP 转 HTTPS 的现有约定；不关闭证书校验。

## 核对结果

后端 `PersonalDishMapper.COLUMNS` 包含 `IMAGE AS image`，V4 按 ID 读取路径复用这些字段。共享列表组件原本已有图片优先分支和圆角。此前原生排版验收的合成菜品明确设置了 `image:''`，其全为简笔画不代表线上菜库全部没有图片。

本次补齐详情缺图/失败占位、图片地址空白处理、过期失败事件保护，保留原图字段与既有页面操作。

## 图片源限制

抽取本地历史 CSV 中 cp1.douguo.net、cp2.douguo.net 各 1 条封面地址，本机 HTTPS 请求均出现证书域名不匹配；其中 cp1 样本在微信工具中亦触发失败占位。这是两条样本的观察，不代表所有图片永久失效，也未确定是否受本机网络链路影响。未修改数据库或批量替换图片源，未关闭安全校验。真实远程照片的成功显示仍需在可用图片源与实际设备上验证。
