# 菜谱与个人内容连续使用

T13保留全部/我的/常用菜单、分类末项横向滚动、临时筛选、已选菜和原写入日志。详情返回保留查询、分类、筛选与滚动位置；滚动事件只记录位置，不逐帧setData回写scroll-top。新条件加载时不显示旧条件可点结果；分页失败仍保留本条件已读列表，并重试原分页。账号或API变化都会清空旧环境浏览缓存。空结果有清空条件入口。

收藏卡片保留contentVersion、quality与cookMinutes，继续真图优先及失败后回退；只有已选菜、待核对或选择忙时出现底栏。原取消收藏确认与加入本餐流程保留。

主时间标签只采用ESTIMATED或VERIFIED依据；原cookTime及cookMinutes仍可在补充资料阅读，不把UNKNOWN当成已核对时长。这调整了旧“只要有数字就在主信息显示”的测试合同；新增未知/预计/核验三组覆盖，未删除原资料。

个人菜仍先填名称、分类、用料、步骤，其他资料选填；复制编辑后保存才创建，取消/原请求恢复/来源下架回归保留。常用菜单使用前继续原版本与保留菜冲突确认。
