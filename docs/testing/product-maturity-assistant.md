# 助手成熟度实施合同

## T07：只读扩展与澄清

已实现11类只读工具：原8类加合法筛选词典、当前用户收藏和常用菜单。新增工具仅在扩展开关开启且Java/Python协议探测通过后提供；开关默认关闭，不影响原8类及3类动作。收藏和菜单按认证账号读取，菜单同名仍按ID/version区分，分页不创建或应用菜单。结果按字符预算整行裁剪，不伪造份量、价格或已下架菜品。

澄清仅有日期/餐次、菜品指代、来源、人数四类，每次最多4选项。供应商可以声明clarificationKind；Java按已有规范问句及当前授权事实生成实际选项，忽略模型自造选项或日期。普通客户端仍收到原问句。

选择提交包含原turn引用和optionId，可选日期仅用于“选择日期”。服务端在新turn入库的同一事务、同一用户锁内校验原会话、工作区、版本、10分钟期限及尚未消费状态；同一requestId重放返回原turn，新requestId不可消费同一卡第二次。冲突不消费，入库失败随事务回滚。实际MySQL回滚证据归T21，不以Mockito替代。选择后的模型上下文含原用户意图及服务器重读的选择事实，不附带执行令牌、不授予写入批准；日历及采购仍走原预览确认。

实现细分为AssistantPersonalReadService（只读）和AssistantGuidanceService（选择），避免在原8类读取服务中混入续办状态。没有独立重复的写入引擎。

验证：Java助手合同/上下文/预算/状态及调度103项通过；Python助手隔离89项，88通过、1项跳过。新增测试覆盖空收藏、同名不同ID、归属、合法词典、分页、过期/旧版本/其他账号/会话/伪选项/重复消费及原请求恢复。未访问外部模型或生产数据库。界面渲染及点击在T17接通；历史在T08接通。
