# 助手成熟度实施合同

## T07：只读扩展与澄清

已实现11类只读工具：原8类加合法筛选词典、当前用户收藏和常用菜单。新增工具仅在扩展开关开启且Java/Python协议探测通过后提供；开关默认关闭，不影响原8类及3类动作。收藏和菜单按认证账号读取，菜单同名仍按ID/version区分，分页不创建或应用菜单。结果按字符预算整行裁剪，不伪造份量、价格或已下架菜品。

澄清仅有日期/餐次、菜品指代、来源、人数四类，每次最多4选项。供应商可以声明clarificationKind；Java按已有规范问句及当前授权事实生成实际选项，忽略模型自造选项或日期。普通客户端仍收到原问句。

选择提交包含原turn引用和optionId，可选日期仅用于“选择日期”。服务端在新turn入库的同一事务、同一用户锁内校验原会话、工作区、版本、10分钟期限及尚未消费状态；同一requestId重放返回原turn，新requestId不可消费同一卡第二次。冲突不消费，入库失败随事务回滚。实际MySQL回滚证据归T21，不以Mockito替代。选择后的模型上下文含原用户意图及服务器重读的选择事实，不附带执行令牌、不授予写入批准；日历及采购仍走原预览确认。

实现细分为AssistantPersonalReadService（只读）和AssistantGuidanceService（选择），避免在原8类读取服务中混入续办状态。没有独立重复的写入引擎。

验证：Java助手合同/上下文/预算/状态及调度103项通过；Python助手隔离89项，88通过、1项跳过。新增测试覆盖空收藏、同名不同ID、归属、合法词典、分页、过期/旧版本/其他账号/会话/伪选项/重复消费及原请求恢复。未访问外部模型或生产数据库。界面渲染及点击在T17接通；历史在T08接通。

## T08：新助手历史

GET /assistant/v4/sessions以认证用户、(updatedAt,id)倒序游标分页，默认20、上限50。摘要只含目标、状态及工作区引用，不查询或返回整段消息。关闭助手后历史仍可读取和删除；创建、继续发送、续办写入仍受能力开关约束。原会话读取新增当前目标和latestTurn，重启可核对原任务。新增V8_20仅补缺失的用户/时间/ID索引，不改旧SQL；尚未在生产执行。

历史页优先展示餐桌助手记录，旧版记录折叠。浏览与继续分别操作；继续先重读原会话，再按原日期/餐次加载并核对workspaceId。原会话404或工作区不一致时不创建替代会话、不自动导入。相同会话复用本地未知请求；选择其他会话用独立绑定保存，不覆盖原会话待核对证据。删除会话只使用原删除接口，不删除日历、采购、实吃。

验证：Node47项通过（新历史、旧导入、未知请求、跨账号及原输入/确认恢复）；Java105项通过，含同时间游标和归属/非法分页。UI模板重新生成。原生点击及真实MySQL游标/索引验证归T21/T23，未以单元测试冒充。

## T09：安全交接到原有页面

供应商新增有条件的navigation建议，类型仅限record_actual、edit_preferences、edit_shopping、copy_recipe、save_personal_menu、use_personal_menu、view_favorite。它们不是新增写工具；ACTIONS仍只有3类。Java按认证用户重读菜品/收藏/菜单/采购及工作区，校验引用和版本，再生成10分钟交接卡。不接受模型URL、数量、价格或“完成”声明；预填只带用户原句，不应用模型猜测的偏好增量或食材克数。缺目标先澄清，旧客户端只显示入口说明。

小程序使用账号/API范围内的10分钟一次性本地令牌，路由由枚举映射。目标页重新读取：

- 实吃打开指定餐次的现有变化记录编辑框；原未知请求仍优先。取消无写入。
- 长期偏好先完整读取原设置，呈现用户原句供核对，再由用户用原控件编辑和保存；不把临时本餐要求自动存为长期偏好。
- 采购用itemId及清单version定位；同名不同形态、部位不会被文本匹配误选；已有表单或未知操作时保留原输入。
- 复制直接进入原编辑副本流程，仍只在保存时创建。查看收藏重新读取菜谱详情。
- 保存常用菜单重读原工作区版本后进入现有命名流程；复用菜单重读菜单version后打开指定目标核对，不自动调用应用。

复用既有实吃/收藏详情及菜单resolve流程，未另建保存接口。用户从目标页返回时没有业务回执就不显示助手“已完成”；不会为了展示成功而额外提交。

协议探测升级为maturity.2，避免早期maturity.1 Python（尚未完整实现交接）被误判为配套版本。扩展默认关闭；最终候选配置中列出匹配启用要求。

连续澄清保留原始任务和先前已确认选择，不让“选了明天，再选午餐”丢失日期或原保存意图；这些仍只是输入事实。

验证：Node242项通过，含真正目标页的菜单/副本取消、采购精确条目、实吃编辑无写入；Java助手范围108项通过后，最终48项定向回归通过；Python91项隔离运行89通过、1跳过、1项预算文件替换遇到Windows文件访问失败，失败用例所在14项预算入口测试单独重跑全部通过。未发送真实模型请求；真实事务和原生操作归T21–T23。T17补齐卡片视觉、澄清按钮与历史失效展示。
