# 采购与费用（T15）

待买/已买、食材汇总/按菜查看、来源展开、勾选撤销及原请求恢复沿用现有链路。空清单增加从日历准备入口，餐次来源、形态和部位不合并丢失。预览只依据真实加入回执显示结果，家里已有的项目仍不提交。

费用默认折叠，只有主动展开才等待登录并探测原有价格/支出能力。价格查询按现有500项合同分批，账号、环境、清单版本和请求序号都匹配才接收；404复用五分钟退避。没有报价服务时实际支出仍可独立填写，清单操作不依赖费用服务。

报价保留实际日期，未知用量、手动用量、不可换算单位不估价；缺失金额展示“—”，0元展示¥0.00。实际支出按当前汇总食材记录一次，不分摊到菜品，不新增历史账本。不自动开启未配置商超跳转。编辑期间清单版本变化会要求重新选择食材，取消不保存。

122项Node检查通过，包含费用按需读取/迟到响应、缺金额、0元、部位区分、未知/不可换算用量，以及原采购预览、跨餐来源、回执、重复请求、撤销和草稿恢复检查。该结果不代表真实数据库、价格来源采集、原生键盘和线上能力已验收，分别留T21/T23。
