## 取消的保证与剩余限制

Java 的编排线程与 HTTP 线程池是两个独立资源。原 `HttpURLConnection` 对线程中断不可靠，且同步 `disconnect()` 在慢响应体测试中也会阻塞；没有将该实验性方式保留。经本批技术决定，只为助手网关增加当前 Spring Boot BOM 管理的 Apache HttpClient 4.5.14，通过每请求的 `HttpRequestBase.abort()` 关闭连接。Java/Spring 版本和其他 HTTP 调用不改，默认 TLS 验证保留。

网关及协议探测共用有界两位 HTTP 执行器和两连接上限，原截止时间保留；禁止自动重试、重定向和 Cookie 管理。真实回环测试分别覆盖响应头未到、响应体停滞：取消后编排调用返回、实际 HTTP 两位退出、第三次请求可进入。数据库终态、迟到写入拒绝及已完成回执规则不变。

Python 断连监测只对该 HTTP 请求的工作任务生效，ASGI 与可取消客户端替身已验证对应 provider 占位退出，并保留另一请求。如果代理未及时传递断连、网络/系统调用未响应取消，原有 deadline 仍为回退边界。没有真实供应商取消验证，不能承诺供应商停止计算、停止计费或退还已发生费用；已提交业务不会因停止而撤销。版本选取遵循现有 BOM，本轮未声称该库是最新版本或通过全仓安全审计；依赖维护升级单独评估。
