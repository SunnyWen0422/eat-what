- 位置：`AssistantV4TurnService.runTurn`、`AssistantGuidanceService.validateChoice`、`AssistantV4ContextService.build`。
- 原因：服务端已校验的 `meal_requirement / keep` 仅作为上下文交给模型。后续执行器仍可执行模型返回的有效 `draft_update`，与用户选项冲突。
- 复现：构造已授权的保留选择，受控模型返回调整动作；原代码调用草稿执行器一次。
- 修复：从服务端校验后的上下文识别该明确选择，直接完成本轮并保留当前菜单只读卡片；不生成业务回执、不创建后续工作流、不预留供应商调用。

### R2 / P2：相同用时可以被说成“更快”

- 原因：`equal` 与 `less_than` 都被标记为支持比较措辞，导致两个15分钟的菜可以通过“其中一道更省时”的校验。

- 修复：只有已验证的严格小于关系才能支持已有的“更快/更省时”等比较词；相同用时的普通说明仍可自然表达。

### R3 / P2：连续点击历史对话可永久停留在加载态
