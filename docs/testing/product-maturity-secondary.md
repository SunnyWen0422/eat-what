# 我的、设置、同步和管理页（T18）

“我的”继续使用常用内容、偏好设置、账户与恢复三组；恢复入口统一为“待核对与同步”。没有已同步本机副本时隐藏清理按钮，复制、助手、实际用餐及采购的原恢复入口继续保留。启动日志仍明确为本机启动时间，不作为饮食记录。

常用人数只影响新建餐，单菜用时与本餐整餐用时保持分离。人数编辑允许保留暂时无效的原输入并给出字段错误，不能静默保存旧值。偏好读取失败先重读；保存中或切账号后的迟到事件不能改旧表单。保存抛错会结束等待、保留输入，并不虚报已保存草稿。原成功、离线草稿及跨账号测试保留，测试夹具明确模拟已经结束加载的表单。

资料、筛选和管理原生字段增加可读名称；管理六页补充大字输入高度、换行及概览自适应，不修改权限或管理服务。审计页先显示中文操作/结果，技术明细按需展开，复制诊断需主动点击。关于页如实说明模型使用的必要上下文、确认边界、未开放语音和图片回退。

验证命令及实际数量见本次实施台账与日志；包含偏好失败/账号迟到、管理身份和分页回归、统一恢复及资料入口测试，另有2项UI结构检查。原生字体、键盘、读屏及管理权限真实服务验收仍待T21/T23。
