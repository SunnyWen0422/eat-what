# 助手界面与澄清连接（T17）

餐桌助手沿用F，当前餐一行、菜单默认折叠、最多四个开始建议。澄清卡只展示服务端授权的最多四个选项；日期选择使用原生选择器。发送携带原continuationRef和optionId，服务端仍校验所有权、版本、过期及是否已使用。该选择是补充输入，不是业务写入授权。未发送输入需要替换确认，取消不操作。

同一任务仅保留一个当前可操作卡；历史卡和会话历史中的卡片可读、可看菜谱，但不能重新确认或重放交接。回到前台重新检查能力，停用后保留阅读界面并禁用发送、确认、选项和草稿撤销；后台仍为最终写入防线。进度只显示排队或正在处理，页面隐藏后停止安排新的轮询。

上划读旧消息时收到更新只提示“查看新消息”；主动发送或选择该入口才回到底部。输入变化不再触发自动滚动。短成功回执及目标去向仍由真实receiptRef驱动，采购只显示实际加入项，交接继续使用原确认页。

修复恢复时的父轮误认：提交子轮后丢失响应，再读到上一轮latestTurn，不清除未知子请求。后续核对仍重试原UUID/原请求体，防止丢失恢复线索。

80项Node助手/历史检查及2项UI结构检查通过；包含澄清选项、日期验证、未知恢复、旧卡失效、能力停用、未发送输入和阅读历史的滚动规则。未调用外部模型，也未进行原生滚动/日期选择器/键盘验收；对应T22/T23尚待执行。
