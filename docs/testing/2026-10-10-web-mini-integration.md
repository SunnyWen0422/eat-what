目标分支：`codex/v4-meal-workspace-green-20261003`，原远端 `8bc8d8b`。网页来源：`codex/independent-web-20261009` 的 `847064e`，加上本次兼容、启动和验证修复。用户已授权通过检查后合并；生产全面升级仍是单独边界。

## 合并影响

- `web/` 是独立 React/Vite 工程，有自己的锁文件、依赖、构建与本地记录。小程序 `project.config.json` 明确排除整个 `web/`，没有替换小程序页面、样式、导航、图片或事件。
- Java 新增公开菜库专用 Controller、DTO、Mapper、配置与权限回归；原 `/dishes`、微信登录和个人记录接口保持认证契约。公开目录默认关闭、编号为空，只发布显式批准且已发布的系统菜，私人菜不进入匿名查询。网页个人记录仍存在浏览器，不能声称两端已同步。
- 根验证脚本识别 npm 锁文件合法键并排除依赖/生成目录，新增网页检查；已有小程序、Python、Java检查保留。接手后需在 `web/` 执行 `npm ci` 才能运行全仓验证。
- 小程序 API 恢复 HTTPS 线上地址，保持 V4；登录采用真实微信 code。相同编号的本地与线上账号不共用缓存、工作区、待提交操作或回执。旧缓存保留，只有存在明确旧 API 环境记录时才复制到原环境的新键，不覆盖更近的数据，不重放到线上。
- 网页新增 `npm run dev:online`，只代理公开目录 GET，校验证书且剥离账号凭据；测试始终关闭代理。静态发布仍须服务器配置同源 API。
