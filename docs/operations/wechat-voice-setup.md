# 微信官方语音输入启用

饮食助手使用微信官方同声传译插件 WechatSI 将语音转成可编辑文字。用户核对后自行发送；
录音上限 30 秒，文字连同原草稿不超过 2000 字。不需要另建腾讯云账号、密钥或语音后端。

默认源码不声明插件，专属加载文件也不引用插件，未开通的小程序可以继续正常使用打字。
语音入口仅在插件已配置且运行时能取得识别管理器时显示。

## 启用

先由小程序管理员在微信公众平台的插件管理中添加“微信同声传译”，核对插件 ID
`wx069ba97219f66d99`，并记下后台实际可用的发布版本。
入口位置可能随公众平台调整，以当前后台为准。

随后在项目根目录执行以下命令，将 `X.Y.Z` 替换为后台显示的真实版本：

```powershell
python scripts/configure_wechat_voice.py --enable --admin-enabled --version X.Y.Z
```

工具只维护 `app.json` 内的 `plugins.WechatSI` 和专属
`utils/wechat-voice-plugin.js`，保留其它页面、设置和插件。
它校验版本、插件 ID 及专属文件模板；遇到人工修改会拒绝覆盖。两份文件先暂存，
写入失败时尝试恢复原件；若自动恢复也失败，会保留恢复副本并明确报告路径。
当前后台授权、插件最新版本及实际编译仍需在微信开发者工具核验。

## 停用

将 `X.Y.Z` 替换为已启用的准确版本：

```powershell
python scripts/configure_wechat_voice.py --disable --version X.Y.Z
```

此操作移除该插件声明并恢复不引用插件的默认加载文件，打字仍可使用。
它不会卸载管理员后台中的插件，也不会发布小程序。

## 验证边界

本地模拟覆盖草稿保留、停止、取消、权限失败、晚到回调、会话隔离及启用工具恢复。
这不等于真实录音验证。正式启用后仍需在微信环境验证授权界面、录音停止、临时音频清理、
弱网/前后台及识别效果。插件管理器缺少会话标识；实现依赖其正常结束回调作为录音边界。
若停止后始终没有结束回调，会停用该管理器直至重启小程序，继续允许打字。

接口依据为[微信团队官方示例](https://github.com/Tencent/Face2FaceTranslator)：
使用全局识别管理器，读取识别文字和临时录音路径；
[官方插件文档](https://mp.weixin.qq.com/wxopen/plugindevdoc?appid=wx069ba97219f66d99)
需在微信平台环境查看。本次无法直接读取平台文档，未将示例中的历史版本当成当前最新版。
