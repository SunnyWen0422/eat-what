## 本轮修复与启动契约

公开菜库缓存按 API 来源隔离，旧无来源数据保留但不误用；预加载、请求和推荐回退阻止旧环境迟到响应污染当前环境，轻量读取明确限定范围。用户操作与回执继续保持账户/服务边界。

Java 使用私有 SHA256 固定快照，避免占用构建输出。默认重启沿用保存包，显式 `--jar` / `-JarPath` 更新；`check-jar` 校验准备而不停止服务。包无效、归属不符、保存哈希漂移或内嵌私密配置会被拒绝。

私有配置与运行记录的数据源、端口、Token 在停止前核对，父环境的 Spring/JVM 覆盖选项不传给本机服务。监听归属、活进程与健康共同验证就绪；外部环境占用端口、进程已退出或归属无法读取时拒绝成功。此保护的单位回归与当前实际可见性分别记录，普通终端的体验证据不掩盖执行隔离限制。

显式 `adopt-running` 可在能看到实际监听的普通终端修正历史错误运行记录，先保存新私有备份，仅更新 Java PID/包字段；不操作进程、数据库、Token 或预算。严格识别保存快照或本项目旧 JAR，旧布局不伪装成新包；恢复后须用最终候选明确重启。默认启动不自动收养，当前隔离环境未实际执行恢复。

普通启动不自动运行模型，外部模型统一测试延后；语音不可用。质量未知不补造、审核不伪升，缺价空缺，实际支出与参考估算分开。
