# 轻字重与分割线

用户要求所有页面去掉过重黑体，保持醒目、轻巧，并加深做法页分割线。

- 正文常规字重 400，菜名、分区标题和操作强调最多 500；移除模板中的 117 处 600/650/700/bold 声明。
- 主页面保留深松绿宋体标题，使用 400 字重及既有微字距；其他内容使用系统无衬线字体回退链，不下载字体。
- 标准字号比例保持 1，字号、触控尺寸及布局规则保持不变。
- 公共分割线统一为灰绿色 `#B8C5B8`；做法标题横线与步骤间横线同色。原先使用分割线色作为控件底色的地方改用独立 `controlSoft`，保持原底色。
- 修改设计模板后重新生成 WXSS 及令牌文件，避免下次构建覆盖。

验证范围：扫描全部 27 个注册页面所用的 53 个 WXSS 文件，无超过 500 的字重声明；51 份清单内生成样式与模板一致；54 项相关组件及标准字号检查通过。原生截图验收使用禁止业务网络的合成数据，检查主页面、详情、列表、弹窗和助手展示；不代表真实设备字体字形一致，也不包含发布或线上验收。
