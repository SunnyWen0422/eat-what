# 饮食助手页面精简

## 目标与范围

改善空白会话中标题重复、说明过长、按钮厚重和输入区分散的问题，延续轻透浮层 F。调整当前小程序助手页面的 WXML、样式模板及快捷建议定义；不修改模型、业务接口、会话状态机或兼容助手流程。基线 0a1057f，保留工作区已有购物清单和首页透明图标修改。

## 实现

- 标题只保留微信原生导航栏的“饮食助手”。内容顶部合并餐次、人数、菜单数量与返回箭头，删除“查看来源与菜单”长说明；下拉箭头提示可展开，辅助标签保留完整含义。
- 返回继续使用原来源导航逻辑和对应辅助标签，不把来自菜谱、日历的返回强行改为首页。
- 空会话显示“这餐想怎么吃？”与左对齐的四行快捷入口。点击沿用原输入预填流程，不自动发送；具体文字与最新调整见下。
- 展开内容分为“本餐设置”“长期偏好”，标签和值分列对齐；修改/编辑入口与标题同排，保留原禁用条件及偏好读取失败提示。
- 底部输入框和发送按钮整合为圆角轻透输入栏；缩小字体、移除输入框硬边框，普通与大字号垂直居中。单行与多行继续采用原生自动高度，保留键盘避让与安全区逻辑。
- 菜品卡片、停止、补充、操作核对、草稿恢复及错误提示保留。大字号允许餐次信息自然换行，但不拆开“2人”等字段。

## 同日后续：四行快捷入口

按用户后续反馈移除空会话顶部四角星，标题与列表左对齐。入口采用透明背景、浅分隔线、小图标与右箭头；每行不少于 48px 点击区域。四行分别为：

1. 帮我搭配这一餐：预填“按当前人数和要求安排这餐”。
2. 推荐清淡一点的：预填“按本餐人数和要求，推荐一份清淡的菜单”。
3. 查看现有安排：预填“看看我已有的用餐安排”。
4. 今天吃得健康吗：预填“看看我今天实际吃得是否均衡，有什么可以调整的？”。

最后一项使用现有实际饮食回顾能力；本轮只新增入口，不新增评分算法，也不把计划菜单视为实际用餐。两个推荐入口、安排入口与健康入口在助手可用时统一展示。保留已有输入覆盖确认、账号切换、处理中及待核对状态的保护。
