- 普通页面温暖餐桌 A；菜品卡片、菜品内容和餐桌助手轻透浮层 F。

## 本轮修正

1. **减少重复信息**：删去“合并为几行”、重复选菜入口、头像上传过程说明、正常同步状态和重复分组。失败、未保存和结果未知仍保留。
2. **统一菜品呈现**：旧结果页与旧助手推荐也使用共享菜品行，图片/占位、圆角、星标和换菜操作保持一致。
3. **收紧采购页面**：两组切换有清楚的主次；用量提示缩为食材旁的小字，仍可调整数量和查看原始来源。
4. **修正输入排版**：共享输入框去掉造成文字偏下的垂直内边距，保持原有输入区域和触控高度。
5. **统一次按钮和标题**：菜谱分类、管理页次按钮使用浅绿实底；“日历 / 餐次详情 / 个人资料 / 餐桌助手”等命名统一。
6. **修复弹层内容遮挡**：原生复现了搭配末行覆盖底部按钮；修正滚动区域裁切，并验证末行仍能滚动到按钮上方。
7. **校正说明与细节**：使用说明与当前助手直接执行约定一致；同步恢复卡片补齐圆角，管理入口保留无障碍语义。

搭配弹层问题在原生合成场景中复现：滚动区末行超出可见边界，文字露到固定底部按钮上。修正在 `design/wxss/components/ui-sheet/ui-sheet.tpl` 的滚动内容裁切；保留 `overflowChrome` 整体滚动模式。原生滚动后末行底部约 538 px，底部操作区顶部约 573 px，确认最后一行仍可到达。没有仅覆盖文字而关闭滚动。

采购中的“用量待核对”是数量信任状态，仍以小字保留。菜谱原文可读并不表示可以按人数换算；本轮没有把未审核数量改成可信状态。管理页的用户 ID、审计对象和状态是管理所需信息，不按普通用户页面一律删除。
