# 日历页面精简

开始日期：2026-10-18；补充调整与验收：2026-10-19。基线 HEAD `c04d92e83607188b6b4d2b0b82ad81a013fc68f9`，沿用本地已有食材/收藏改动；本次调整小程序日历、餐次详情展示与已要求移除的入口。

## 已实施

- 去掉日期整列白色长按钮。日期按钮背景透明，选中数字用深绿圆形底色；仍保留至少 44px 点击区域。
- 空餐次不渲染“还没有安排”和它占用的正文区域，只保留“没有记录”及右侧轻量“安排 ›”。已有计划或明确用餐记录时显示“查看 ›”。整张卡片可点击，不再单独放带底色的大按钮；共享餐次组件其他入口保留原有行为。
- 已吃过的餐次直接展示实际菜名，不在标题旁重复“已记录吃过”。有安排但没有实际记录时只显示“已安排”，不叠加“没有实际记录”；明确没吃时保留一处“这餐没吃”。实际记录缺少菜品时显示“暂无菜品明细”，绝不拿计划菜名冒充实际。
- 餐次详情同步精简重复状态和空态，人数仍可显示且不会多出分隔符。菜名和人数完整可读。
- 删除日历首页“更多”、其弹层，以及三个专属事件：周期食材准备、购物清单、选择一餐继续安排。单餐详情和其他页面的购物/助手功能未改动。
- 仅当当前周期存在计划或实际记录标记时显示简短图例；空周期不显示无关图例。

## 不变的业务约定

计划不等于吃过；“排”和“记”可同时显示，不合并成完成状态。日期完整无障碍描述、月历空白格不可点击、日期选择回传、登录/读取失败、餐次详情导航继续保留。本次没有新增写接口，也不改变数据库或后端协议。

## 同类文案检查

- 清理：日历列表、餐次详情中的记录成功常驻标签、叠加状态，以及标题和正文重复的缺失/没吃说明。
- 保留：饮食回顾的记录数量、缺失统计和折叠的计算说明，它们表达数据含义；记录操作后的即时成功反馈、读取失败与恢复入口表达当前操作结果。
- 兼容入口、助手和采购摘要也做了关键词检查：跨日期摘要里的餐次状态、实际支出汇总不属于同一张卡片的重复提示。本次未改动这些业务或将检查扩大为全站重设计。
