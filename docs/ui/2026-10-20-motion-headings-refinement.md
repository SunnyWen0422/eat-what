# 默认动效、主标题与偏好精简

基线：`19cb490` 及尚未提交的助手对话改进。范围限小程序界面与偏好展示；本轮没有真实模型请求、生产访问、数据库修改或发布。此前有效的保存、恢复和编辑测试结果按未改变的边界复用。

## 用户结果与约束

- 偏好页移除动效开关，轻量动效默认启用。旧账号 `reducedMotion: true` 被兼容读取为 `false`；读取不回写、不清除原有搭配记忆。保留共享组件显式参数的内部能力，没有新的用户开关。
- 助手去掉自动抑制等待动画的系统媒体规则，不修改设备的系统设置。运行中圆环旋转、提示点呼吸；文案仍按原有生命周期轮换，离页/完成/停止会清理文案定时器。未知结果不冒充正在执行。
- 常用人数改为一行，正常字号下卡片高 64px、输入可点击区域 56×44px，保留 1–50 整数校验及错误展示。
- 日历去掉“某年某月某日的三餐”标题。日期选择、选中状态与无障碍日期说明仍保留。
- 助手恢复入口改为“继续查看结果”，处理过程中隐藏不能操作的恢复按钮。黄色提示使用独立图标和文本布局，单行/多行均共用垂直中心。未知结果已有提示时，不再重复展示静态等待卡片。
- 今天、菜谱、日历的主标题使用深松绿、500 字重、宋体系列系统字体。只添加主标题专属类，不改正文与二级页字体；没有为“我的”重新添加重复大标题。系统字体字形依设备可用字体有所不同。

## 保持的行为

模型意图识别、工具选择、服务器状态和请求次数不变。恢复沿用原操作标识，不创建重复提交；输入保留、停止和补充、保存未知时的只读保护仍生效。常用人数仍通过原偏好保存流程生效，修改显示方式不直接写入日历或本餐。

- 微信开发者工具使用阻断业务网络、禁用业务生命周期的合成场景；10 个原生场景验证覆盖主标题、日历、人数表单、等待、错误与结果恢复。圆环变换矩阵和提示点透明度经过间隔采样确认变化，不能将截图静态外观当作动效证据。
- 320px / 390px、普通 / 1.5 倍字号，共 36 组适配渲染检查：无横向溢出、过小按钮、按钮内容裁切或表达式错误。适配渲染是布局补充，不能替代真机验证。

人工查看原生截图后补查大字号多行错误提示。机器证据、截图、最终源码哈希及预览存于工作区本轮记录；这些本机产物不进入发布包。

未完成范围：Android 真机字体、键盘和安全区未在本轮验证；没有重新评价真实模型回答质量或服务端请求失败原因。用户明确要求定向验证，本轮未运行全量测试。

## 后续：固定顶部本餐设置

用户补充要求顶部区域不能随聊天滚走。原生滚动复现确认：设置卡片位于聊天 `scroll-view` 内，滚动会带走该卡片。修复把设置移到聊天外的独立限高滚动区，餐次栏及底部输入区域留在固定容器中；长设置和编辑表单可独立滚动。当前菜单仍在聊天区，原导航锚点保持有效。

展开/收起和编辑状态切换后重新测量聊天高度。设置输入的键盘事件沿用既有避让处理，只定位设置区当前输入，不改聊天草稿和聊天滚动目标。保存、取消、未知结果及账号隔离规则不变。

定向验证：37 项相关 Node 检查通过；微信工具实际滚动的 6 个合成场景通过（展开、展开大字号、模拟键盘占位、编辑、编辑加键盘占位、收起）。检查包含聊天确实滚动、顶部及底部位置不变、设置不遮盖聊天、应用设置按钮可滚动到达；业务请求为零。键盘占位验证不等于 Android 真机输入法验收。本次未跑全量测试，未推送或部署。
