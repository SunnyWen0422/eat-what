# A 温暖餐桌 + F 轻透菜品：两端实施计划

## 目标与设计依据

以已审阅的 2026-10-13 交互预览为基准：涉及菜品卡片的内容区域采用 F 的浅渐变背景、半透明白色菜品面、轻边界与轻阴影；其余区域使用 A 的暖白、深绿与系统中文字体。所有页面保持同一套交互语义，不将六种研究主题作为可切换产品功能。

- A：背景 #F8F7F2，品牌 #28634E，正文 #25332B，辅助 #56645B。
- F：背景 #E9F0E9；145deg 渐变 #E4EEDA → #F5ECE2 60% → #D7E9E3；菜品面白色 66% 不透明度，白色 74% 边框；16px 圆角、10px 内边距、8px 卡间距、轻阴影。小程序不依赖 backdrop-filter，列表不增加模糊开销。
- 菜图优先，失败或缺失才回退分类图标；缩略图圆角 14px，通常 64px，F 紧凑行 56px；详情图圆角 18px。
- 系统中文字体；24/18/16/13px 层次；按钮可见边界，主要按钮 48px，触点目标 44px；主次操作不只靠颜色区分。
- 删除装饰与重复说明，技术来源/数据细节按需展开。保留真实错误、限制、忌口风险、保存未知、冲突恢复、来源许可、浏览器本地存储边界等必要信息。
- 不修改推荐、计划、实吃、采购、复制事务和助手确认协议；复制仍在编辑保存后创建。
- 用户追加确认：餐桌助手整页、对话气泡和推荐内容均采用 F。输入区保持清晰边界；待确认写入卡使用独立标题、目标餐次与实色确认按钮，不能与普通回复混淆。
