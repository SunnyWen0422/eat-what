# 食材阅读、收藏入口与按钮整理

日期：2026-10-18。基线 `c04d92e83607188b6b4d2b0b82ad81a013fc68f9`，本地未提交修改。范围为小程序展示和收藏交互；没有修改后端、数据库、网页客户端或线上配置。

## 用户结果与保留约定

用户打开菜谱直接看到食材及原有用量；操作菜品时可在“换一道”右侧直接点五角星收藏。延续温暖餐桌 A / 轻透浮层 F、真实图片优先和圆角。保留菜单选择、复制后编辑保存、分享、烹饪步骤、采购核对、失败恢复及账号隔离。

## 展示规则与同类排查

| 场景 | 已调整 | 保留的真实边界 |
| --- | --- | --- |
| 菜品详情 | 优先展示已核实值，否则展示原始证据中的可读用量；两列食材、长内容跨列、大字单列 | 真正缺失显示“未注明”；未通过完整换算时保持原方，不冒充当前人数用量 |
| 原始食材文本 | 结构化拆分名称、量、单位、处理方式，隐藏成人数及冗余统计口径 | 不改原始字段，不把展示结果写回质量或采购计算 |
| 烹饪提示 | 有用提示直接放食材下方，用次级字号和可读辅助色；省略重复步骤、简单方法名及占位词 | 不删原始 tips/methods 数据；步骤继续完整展示 |
| 大字做法、常用菜单预览 | 复用同一食材展示转换 | 不增加自动份量推断 |
| 购物清单、采购预览 | 显示字段去掉内部口径、内部错误枚举；原始来源和后端判定不变 | 用量有疑问时仍保留核对与调整，不能把不能相加的数量当成已汇总 |
| 我的菜谱、助手上下文 | 移除固定质量解释和重复内部说明 | 保存状态、临时与长期偏好边界继续可见 |
| 菜品行、助手、详情、收藏及兼容结果页 | 共用五角星收藏组件，替代冗余三点动作 | 真实菜品 ID、图片与详情关联不变；旧已保留菜品可直接取消保留 |
| 全局次级按钮 | 浅绿实底、透明边框，主按钮维持深绿；相邻换菜/星标统一高度、底色、圆角 | 输入框、复选框、选中筛选及真实错误状态不为消除边框而失去区分 |

详情底部“更多菜谱操作”保留准备食材、复制及本人编辑；这是有独立价值的操作，不是被移除的菜品行三点菜单。

## 收藏状态与接口约定

使用现有收藏接口，没有新增协议。一个账号/API 环境共用收藏快照和读取请求；所有可见菜品星标订阅同一状态。

| 事件 | 行为 |
| --- | --- |
| 初次读取/返回页面 | 登录完成后读取收藏；列表批量读取，避免每张卡片单独请求 |
| 点击及连续点击 | 同一菜品串行处理，显示处理中；收藏和换菜互不触发 |
| 成功 | 依据服务端 success 更新；其他卡片同步，收藏页取消后移除该项 |
| 写入错误/超时 | 先查询真实收藏状态；若已达到目标则确认成功，否则显示失败 |
| 查询也失败 | 保留结果未知，下一次点击先核对，不能直接反向写入 |
| 换账号/API、回收组件、晚到响应 | 旧结果不能更新新身份或被复用的另一道菜 |
| 重启 | 重新读取服务端收藏状态，不依赖本地假收藏 |

收藏写请求不自动重发；单菜核对和批量读取静默，由组件给出简短操作结果。没有为收藏引入模型调用。
