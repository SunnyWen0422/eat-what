# 自定义菜谱用户体验优化

## 问题反馈

用户反馈的问题：
1. 定制完菜谱返回主页后，没有看到自定义菜谱的可勾选选项
2. 用户不知道是否自定义成功

## 优化方案

### 1. 主页增加"我的菜谱"区域

#### 功能特点
- **可见性**：当用户有已保存的菜谱时，自动在主页显示菜谱列表
- **横向滚动**：支持左右滑动浏览多个菜谱
- **选择功能**：点击菜谱卡片即可选择并应用
- **直观展示**：每个菜谱显示人数、荤素汤配置、包含的菜品

#### 视觉设计
```
┌─────────────────────────────────┐
│  我的菜谱      点击应用菜谱配置  │
├─────────────────────────────────┤
│ ┌─────────┐  ┌─────────┐        │
│ │ 家庭聚餐 │  │ 工作日餐 │  ...  │
│ │ 👥 6人   │  │ 👥 2人   │        │
│ │ 🍖 3荤   │  │ 🍖 1荤   │        │
│ │ 🥬 3素   │  │ 🥬 2素   │        │
│ │ 🍲 2汤   │  │ 🍲 1汤   │        │
│ │ ✓ 已选   │  │          │        │
│ └─────────┘  └─────────┘        │
└─────────────────────────────────┘
```

#### 交互流程
1. 用户点击菜谱卡片 → 自动应用配置（人数、荤素汤数量）
2. 显示 Toast 提示："已应用《菜谱名》"
3. 卡片显示绿色选中状态，带"✓ 已选"徽章
4. 可点击"取消选择"按钮取消
5. 点击删除按钮（×）可删除菜谱

### 2. 定制页面增强

#### 菜品配置更完善
在"人数"标签页增加：
- 菜品数量配置（荤菜、素菜、汤品）
- 餐次类型选择（早餐、午餐、晚餐）

#### 菜品选择功能
- **点击选择**：点击菜品可添加到菜谱
- **视觉反馈**：选中的菜品显示绿色背景 + ✓ 标记
- **再次点击**：取消选择
- **计数显示**：顶部显示"已选择 X 道菜"

#### 保存体验优化

**保存流程**：
1. 点击"保存菜谱"按钮
2. 弹出输入框，提示当前配置
   ```
   保存菜谱
   ──────────────
   当前配置：3人餐，已选5道菜
   
   请输入菜谱名称：
   [我的菜谱-3人餐_______]
   
   [留在这里]  [返回主页]
   ```
3. 输入菜谱名称并确认
4. 保存成功后显示详细提示：
   ```
   保存成功
   ──────────────
   菜谱《家庭聚餐》已保存
   包含5道菜品
   在主页可以选择使用
   
   [留在这里]  [返回主页]
   ```
5. 用户可选择留在定制页面或返回主页

**明确反馈**：
- 告知用户保存了什么
- 包含多少道菜
- 如何使用（在主页选择）
- 提供返回主页的快捷方式

### 3. 推荐算法升级

#### 菜谱优先策略

当用户选择了菜谱后：
1. **优先使用菜谱中的菜品**
2. 如果菜谱中的菜品不够，从全部菜品池补充
3. 保持多样性（避免重复）
4. 保持营养平衡

#### 推荐逻辑

```javascript
if (选择了菜谱) {
  // 从菜谱中获取菜品
  荤菜 = 菜谱中的荤菜.slice(0, 荤菜数量)
  素菜 = 菜谱中的素菜.slice(0, 素菜数量)
  汤品 = 菜谱中的汤品.slice(0, 汤品数量)
  
  // 不足的部分从全部菜品中补充
  if (荤菜不够) 荤菜 += 随机选择(剩余数量)
  if (素菜不够) 素菜 += 随机选择(剩余数量)
  if (汤品不够) 汤品 += 随机选择(剩余数量)
} else {
  // 正常推荐流程
  随机推荐
}
```

## 数据结构设计

### 保存的菜谱结构

```javascript
{
  id: 1698765432000,           // 时间戳作为ID
  name: "家庭聚餐",             // 用户自定义名称
  people: 6,                   // 人数
  meatCount: 3,                // 荤菜数量
  vegCount: 3,                 // 素菜数量
  soupCount: 2,                // 汤品数量
  mealType: "dinner",          // 餐次类型
  selectedDishes: [            // 用户选择的菜品
    { name: "宫保鸡丁", type: "meat", ... },
    { name: "清炒西兰花", type: "veg", ... },
    ...
  ],
  createdAt: "2024-01-01T12:00:00.000Z"
}
```

### 存储位置

- **本地存储**：`wx.getStorageSync('savedRecipes')`
- **数据格式**：JSON数组
- **持久化**：每次保存时追加到数组

## 使用流程示例

### 完整流程
```
1. 用户点击"定制菜谱"
   ↓
2. 在"人数"页配置参数
   - 设置人数：6人
   - 荤菜：3道

   ↓
5. 看到成功提示
   - "菜谱《家庭聚餐》已保存"
   - "包含8道菜品"
   - "在主页可以选择使用"
   ↓
6. 选择"返回主页"
   ↓
7. 在主页看到"我的菜谱"区域
   - 显示"家庭聚餐"卡片
   - 显示配置信息
   ↓
8. 点击菜谱卡片
   - 自动填充参数
   - 显示"已应用《家庭聚餐》"
   - 卡片显示"✓ 已选"
   ↓
9. 点击"今天吃什么"
   - 推荐时优先使用菜谱中的菜品

```

## 关键代码改动

- 新增 `onShow()` 生命周期，加载菜谱

- 新增 `meatCount, vegCount, soupCount, mealType` 配置
- 新增 `selectedDishes` 选中的菜品列表
- 修改 `onSelectDish()` 支持选择/取消菜品
- 新增 `isDishSelected()` 检查菜品是否已选
- 修改 `onSaveRecipe()` 弹出输入框

- 新增菜谱优先逻辑
