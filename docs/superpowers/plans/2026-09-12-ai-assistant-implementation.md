# AI 菜品推荐助手实施计划

## 目标

在不删除现有页面、接口、数据和图片资源的前提下，把现有 DeepSeek 对话页升级为可执行的菜品安排助手，并将其作为居中的第五个一级 Tab：`选菜｜定制｜助手｜日历｜我的`。

## 任务

1. **知识检索与推荐核心**
   - 为菜品索引增加别名归一、字段加权检索、结构化约束和可解释命中信息。
   - 增加会话隔离、意图解析、单餐/周期计划、局部换菜和候选校验。
   - DeepSeek 仅用于理解和润色；结构化结果由本地规则校验，模型不可直接写库。

2. **助手服务接口**
   - FastAPI 提供会话创建、读取、消息、删除及操作预览接口；保留旧 `/chat` 兼容接口。
   - Java 增加认证边界和代理接口，统一超时、用户身份、错误格式与限流。

3. **小程序助手体验**
   - 助手加入原生 TabBar 中央位置。
   - 重构对话页为任务入口、条件摘要、方案卡片、换菜/保留/保存日历/加入清单操作。
   - 维持即时回显、超时保留内容、断网提示、用户隔离和安全区布局。

4. **数据工具与测试**
   - 提供可重建索引命令和数据质量审计输出。
   - 覆盖意图、否定、周期、索引过期、用户隔离、重复操作、模型失败及前端交互回归。

## 验收

- 菜品卡片只引用真实菜品 ID；推荐理由不超出数据库事实。
- 禁忌/排除条件优先于偏好；无解时说明冲突，不静默放宽。
- 助手生成的方案可直接进入现有日历和购物清单流程。
- 前端、Python 测试全部通过；Java 测试至少完成编译及相关测试。
- 不提交任何 API key、生产配置或图片替换。
