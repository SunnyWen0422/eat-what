# Eat-What V4 深绿版实施计划

依据用户批准的《主闭环与全量界面实施计划》，个人账号、25 页、三餐主闭环。原接口及权限保留。

## 约束
Java 8/Spring Boot/MyBatis/MySQL 是工作区权威来源；Python 只执行只读 Agent 任务。计划、采购、实际各自独立。所有新写入带 requestId、expectedWorkspaceRevision，方案操作带 planVersion，确认带 expectedPlanRevision。网络调用不进入事务。保留及明确忌口不可降级。深绿 #28634E、暖白 #F8F7F2；44px 触控，48px 主按钮。未确认草稿 30 天、事件 90 天，正式记录及回执永久保留。

## 任务
1. 基准：保存全部 tracked/untracked 快照，验证现有回归，登记 25 页状态。
2. 工作区契约/规则：MealContext、PlanDraft、MealWorkspace；自动午晚餐、早餐、手动模式、锁与十步撤销。
3. 工作区后端：V4 增量迁移、认证接口、事务确认、持久化任务、有界执行器、重启恢复、请求回执及基础事件。
4. Agent 适配：仅 Java 内部凭证访问、15 秒预算、来源/限制校验及规则降级。
5. 视觉基础：单源 Tokens、公共控件、36 图标与 4 Tab 变体、五类插画 SVG/PNG。
6. 前端主闭环：账号隔离工作区、500ms 草稿保存、未知请求恢复、冲突显式处理；首页/选菜/结果/助手/详情/日历/采购/实际/回顾。
7. 全量迁移：其余个人/收藏/自定义/筛选/同步/管理/旧入口，保留路由。
8. 文档与验收：深绿基线副本、详细设计和开发者说明；自动化、真实 MySQL、跨设备、iOS/Android 逐项登记，未执行不得通过。

## 验证
三餐零输入；人数 1–50；手动菜数独立；换一道/保留/单调版本撤销；幂等同 key 不同内容拒绝；计划冲突；任务取消及迟到丢弃；账号切换；离线明确重试；计划和实际不混淆；购物安全汇总；320px、字号、键盘、安全区、旧返回路径。普通文字对比度 4.5:1。
