# Agent 评测规范

## 指标

- 菜品事实准确率和真实 ID 命中率。
- 忌口/过敏硬约束通过率。
- 份量换算准确率。
- 多轮改口和局部换菜保持率。
- 工具选择正确率和无效调用率。
- 用户完成一餐所需时间、追问次数和方案采纳率。
- 日历/购物清单写入准确率、重复写入率和冲突保护率。
- 模型失败时降级提示覆盖率。

## 测试集

至少 120 条真实表达，包含口语、否定、改口、现有食材、人数换算、多日安排、做法、比较、日历冲突、清单增删改、无匹配和超时。

## 通过条件

任何虚构菜品 ID、越权访问、绕过确认写入、违反明确忌口或将失败误报为成功均为阻断缺陷。真实模型评测使用独立 Key 和测试用户，不进入常规 CI。
