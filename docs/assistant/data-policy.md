# Agent 数据权限规范

## 数据分类

| 分类 | 读取 | 修改 |
|---|---|---|
| 菜品基础记录 | Agent 工具 | 禁止 |
| 食材、菜系、标签、做法 | Agent 工具 | 禁止 |
| 当前任务方案副本 | Agent | 允许 |
| 当前用户日历 | 当前用户范围 | 确认后允许 |
| 当前用户购物清单 | 当前用户范围 | 确认后允许 |
| 明确保存的用户偏好 | 当前用户范围 | 用户明确确认后允许 |
| 其他用户数据、Token、密码 | 禁止 | 禁止 |

## 事实与推导

数据库字段是事实。模型可以在当前任务中进行组合、排序和人数换算，但必须记录来源。可计算数值由服务端工具生成；无法计算的数量标记为需要调整或估算。

## 作用域

Java 从认证上下文注入用户身份；Python 仅接受受信任内网请求。每个会话、任务和写入操作都绑定用户作用域。游客会话使用不可预测的临时范围。

## 写入

用户日历和购物清单的新增、修改、删除均需预览、确认、版本检查和幂等键。基础菜库没有 Agent 写入接口。日志不得包含 API Key、完整提示词、完整用户原文或会话凭据。
