# 吃什么 - 微信小程序

一个智能菜品推荐小程序，帮助用户根据用餐人数、菜品偏好和餐次类型，推荐个性化的用餐方案。

## 功能特点

### 核心功能
- 🎯 **智能推荐**：根据人数、荤素配比自动生成3套推荐方案
- ⚙️ **参数调节**：灵活设置用餐人数、荤菜、素菜、汤品数量
- 🌅 **餐次识别**：支持早餐、午餐、晚餐不同偏好
- 📱 **触觉反馈**：操作时有震感提示，提升交互体验

### 新增功能 - 定制菜谱
- ✨ **自定义菜品**：添加个人拿手菜和特色菜品
- 🔍 **智能搜索**：快速查找想要的道菜
- 📋 **保存菜谱**：保存常用配置，一键应用
- 🎨 **个性推荐**：自定义菜品参与推荐算法

## 快速开始

### 开发环境要求
- 微信开发者工具最新版
- Node.js (可选，用于后端开发)

### 本地开发
1. 使用微信开发者工具打开项目
2. 在 `app.json` 中已注册所有页面
3. 直接编译运行

### 页面说明

#### 主页 (pages/index/)
- 设置用餐人数（1-10人）
- 调节荤菜、素菜、汤品数量
- 选择餐次类型
- 点击"今天吃什么"生成推荐
- **新增**：点击"定制菜谱"进入自定义页面

#### 结果页 (pages/result/)
- 展示3套推荐方案
- 滑动切换不同方案
- 点击菜品查看详情
- 支持重新生成

#### 定制菜谱页 (pages/customize/) - 新增
- **左侧分类**：人数、荤菜、素菜、汤品、自定义
- **右侧内容**：
  - 设置用餐人数
  - 搜索和浏览菜品
  - 添加自定义菜品
  - 管理已保存菜品
- **底部操作**：返回、保存菜谱

## 数据流程

### 推荐算法流程
```
用户输入参数 → 筛选菜品池 → 应用餐次偏好 → 
去除最近菜品 → 生成3套方案 → 展示结果
```

### 自定义菜品流程
```
添加自定义菜品 → 本地存储 → 调用API → 
加入菜品池 → 参与推荐
```

## 后端API设计

详见 [API接口规范](./docs/API_SPEC.md)

### 核心接口
- `GET /api/dishes` - 获取菜品列表
- `POST /api/dishes/custom` - 创建自定义菜品
- `POST /api/recipes` - 保存菜谱
- `POST /api/recommend` - 生成推荐

### 技术栈
- 前端：微信小程序框架
- 后端：Spring Boot + MyBatis/JPA + MySQL
- 数据结构：JSON格式

## 功能亮点

### 1. 智能约束系统
- 人数与荤菜上限联动（1人≤2道，3人≤3道）
- 早餐自动限制荤菜数量
- 晚餐自动提升荤菜下限

### 2. 多样性算法
- 维护最近12道菜品窗口，避免重复
- 智能平衡口味（避免全川味）
- 支持营养均衡推荐

### 3. 个性化定制
- 用户自定义菜品无缝集成
- 保存个人菜谱配置
- 一键应用常用设置

## 使用说明

### 基础使用
1. 打开小程序
2. 调整人数和菜品数量
3. 选择餐次类型
4. 点击"今天吃什么"
5. 查看推荐方案

### 自定义菜谱
1. 点击"定制菜谱"
2. 设置用餐人数
3. 选择分类（荤菜/素菜/汤品）
4. 搜索或添加自定义菜品
5. 保存菜谱
6. 返回主页使用

## 扩展开发

### 添加新菜品
编辑 `utils/dishes.js`，在 `DEFAULT_DISHES` 数组中添加：

```javascript
{ 
  name: '菜品名称', 
  type: 'meat', // meat/veg/soup
  calories: 200, 
  protein: 15, 
  tags: ['标签1', '标签2'] 
}
```

### 对接后端API
在 `pages/customize/customize.js` 中实现 `callSaveDishAPI()` 方法：

```javascript
callSaveDishAPI(dish) {
  wx.request({
    url: 'https://your-api.com/api/dishes/custom',
    method: 'POST',
    data: dish,
    success: (res) => {
      console.log('保存成功', res)
    }
  })
}
```
