# 🍽️ 吃什么 - 智能菜谱推荐小程序

一个基于微信小程序的全功能智能菜谱推荐应用，结合个性化定制、AI推荐算法和日历管理，帮助用户科学规划每日饮食。

## ✨ 核心功能

### 🎯 智能菜谱推荐
- **多维度参数调节**：荤菜、素菜、汤品、主食和甜品数量灵活配置
- **完整筛选**：支持菜系、口味、场景、饮食、做法、忌口食材和最长用时
- **长期偏好**：偏好菜系/标签、永久排除和近期重复窗口可同步到账号
- **后端优先推荐**：生成3套个性化方案，候选不足时明确提示，本地规则仅用于网络降级
- **触觉反馈**：操作时震动提示，提升交互体验

### 🛠️ 个性化定制
- **自定义菜品**：添加个人拿手菜和特色菜品
- **智能搜索**：统一支持关键词、分类、菜系、标签、做法和时长筛选
- **菜谱管理**：保存常用配置，一键应用
- **营养均衡**：自定义菜品无缝集成推荐算法

### 📅 智能日历管理
- **菜谱记录**：保存每日早餐、午餐、晚餐的菜谱方案
- **灵活日期选择**：支持保存到今天或任意未来日期
- **可视化日历**：月份视图直观展示有记录的日期
- **历史回顾**：点击日期查看当天完整菜谱，避免遗忘食材采购

### 📊 饮食统计分析
- **数据统计**：统计本月荤菜、素菜、汤品的记录数量
- **热量估算**：智能估算总热量和日均热量摄入
- **月份切换**：支持查看历史月份的饮食数据
- **智能建议**：根据饮食数据生成个性化饮食建议

### 🛠️ 移动端后台
- **隐蔽入口**：管理员在个人中心连续点击版本号 5 次进入，后端仍会校验管理员身份
- **用户检索**：按用户 ID、昵称或手机号搜索，支持分页加载和下拉刷新
- **代用户加菜**：查看指定用户详情，并通过全屏表单添加或删除其自定义菜品
- **移动适配**：触控区、窄屏排版、长文本换行和底部安全区均按小程序移动端约束处理

### 🔄 智能约束系统
- **动态参数联动**：人数与荤菜数量自动关联调整
- **餐次偏好优化**：早餐清淡、晚餐丰富、午餐均衡
- **多样性保证**：维护最近12道菜品窗口，智能去重

## 🚀 快速开始

### 环境要求
- **前端开发**：微信开发者工具最新版
- **后端开发**：JDK 8+（本地验证使用 JDK 21）、Maven 3.6+、MySQL 8.0
- **部署环境**：Linux + Nginx + Java + MySQL，具体见 `SERVER.md`

### 本地开发

#### 小程序端
1. 克隆项目到本地
2. 使用微信开发者工具打开项目根目录
3. 在开发者工具中编译运行

#### 后端服务
```bash
cd backend
mvn clean install
mvn spring-boot:run
```
服务将在 `http://localhost:8080` 启动

### 生产部署
详见项目中的部署相关文档（已整理到后端API文档中）

## 📱 功能详解

### 🏠 主页 (pages/index/)

- **餐次展示**：早餐、午餐、晚餐三栏布局
- **菜谱记录**：显示当日各餐次的菜谱详情
- **操作管理**：添加、修改、删除餐次记录

- **用户信息**：显示用户头像、昵称、等级

### 📊 饮食统计页 (pages/statistics/)
- **月份选择**：支持切换查看不同月份的统计数据

- **智能建议**：根据饮食数据生成个性化建议

## 🔧 技术栈

### 前端技术栈
- **框架**：微信小程序原生框架
- **语言**：JavaScript (ES6+)
- **样式**：WXSS + Flexbox布局
- **状态管理**：页面级数据绑定 + 本地存储

### 数据流程
```
用户操作 → 前端页面 → API调用 → 后端服务 → 数据库 → 返回结果 → 页面更新
```

## 🎯 使用指南

### 基础使用流程
1. **设置参数**：在主页调整用餐人数和菜品偏好
2. **生成推荐**：点击"今天吃什么"获取AI推荐
3. **选择方案**：浏览3套方案，选择心仪的菜谱
4. **保存记录**：选择保存日期和餐次，记录到日历
5. **管理历史**：通过日历查看和管理历史菜谱

### 日历功能使用
1. **查看记录**：点击底部导航栏的日历图标
2. **选择日期**：在月份视图中点击具体日期
3. **管理餐次**：在详情页添加或修改各餐次菜谱
4. **规划未来**：提前保存未来几天的菜谱规划

### 自定义菜品
1. **进入定制**：主页点击"定制菜谱"
2. **添加菜品**：在自定义分类中添加个人菜品
3. **搜索使用**：在其他分类中搜索并添加到推荐池
4. **保存配置**：保存常用的人数组合

## 📋 开发指南

### 添加新菜品

普通用户菜品通过小程序“定制菜谱”添加。系统菜后续增删改以 `outputs/dish-replacement-20260718/` 的 6,665 条离线基准为准：修改源工作簿后运行 `scripts/replace_dish_data.py` 和 `scripts/backfill_recommendation_metadata.py`，检查审计报告，再执行完整测试。不要只修改 `utils/dishes.js` 的小型离线兜底数据。

### 自定义推荐算法
主推荐逻辑位于 Java `RecommendationService`；`utils/recommend.js` 只维护网络失败时的同条件降级逻辑，两侧硬筛选语义必须保持一致。

### 扩展API接口
1. 在后端添加新的Controller方法
2. 在 `utils/api.js` 中添加前端调用方法
3. 更新 `DEVELOPER.md` 和对应测试
